British Oceanographic Data Centre (BODC), acting as the Global Center for The Nippon Foundation-GEBCO (General Bathymetric Chart of the Ocean) Seabed 2030 Project, archived these data with the Centre for Environmental Data Analysis in 2026. For the GEBCO 2026 release, all file formats and grid types are included as part of the published data holding. The citation for these data should read:

GEBCO Bathymetric Compilation Group 2026 (2026). The GEBCO_2026 Grid - a continuous terrain model for oceans and land at 15 arc-second intervals. NERC EDS British Oceanographic Data Centre NOC. doi:10.5285/4f68d5c7-45eb-f999-e063-7086abc036fa

The GEBCO 2026 BODC Published Data Library catalogue record may be found at: https://www.bodc.ac.uk/data/published_data_library/catalogue/10.5285/4f68d5c7-45eb-f999-e063-7086abc036fa

Inside the GEBCO 2026 release, multiple data types and formats are available. The data types and formats available are:

Standard grid - ice-surface elevation
	/bodc/gebco/gebco_2026/ice_surface_elevation/
		ESRI ASCII raster - 8 tiles, or zipped folder containing all tiles, terms of use and documentation
		GeoTIFF - 8 tiles, or compressed folder containing all tiles, terms of use and documentation
		NetCDF - global grid, or compressed folder containing global NetCDF grid, terms of use and documentation

Grid including sub-ice topography information for Greenland and Antarctica
	/bodc/gebco/gebco_2026/sub_ice_topography_bathymetry/
		ESRI ASCII raster - 8 tiles, or zipped folder containing all tiles, terms of use and documentation
		GeoTIFF - 8 tiles, or compressed folder containing all tiles, terms of use and documentation
		NetCDF - global grid, or compressed folder containing global NetCDF grid, terms of use and documentation

Type Identifier Grid - this indicates the type of source data that the corresponding grid cell in the bathymetric grid is based on
	/bodc/gebco/gebco_2026/type_identifier_grid/
		ESRI ASCII raster - 8 tiles, or zipped folder containing all tiles, terms of use and documentation
		GeoTIFF - 8 tiles, or compressed folder containing all tiles, terms of use and documentation
		NetCDF - global grid, or compressed folder containing global NetCDF grid, terms of use and documentation
